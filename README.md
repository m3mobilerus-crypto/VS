# GL 350 BlueTEC — сервисный журнал

Один файл: `index.html`. Данные лежат внутри него, никакой сборки и никаких зависимостей.
Открывается двойным кликом с флешки, с телефона, из GitHub Pages — везде одинаково.

## Опубликовать на GitHub

1. Создать репозиторий (можно приватный — Pages работает и для приватных на платных тарифах;
   для бесплатного нужен публичный).
2. Положить в корень `index.html` и этот `README.md`.
3. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
4. Через минуту журнал будет по адресу `https://<логин>.github.io/<репозиторий>/`.

Добавить на телефон как иконку: открыть адрес в Safari или Chrome → «Поделиться» →
«На экран "Домой"». Дальше открывается как приложение.

## Дописать визит на сервис

Открыть `index.html` в любом редакторе (или прямо в GitHub — карандашик), найти `const EVENTS`
и добавить блок первым в списке, по образцу соседних:

```js
{d:"2026-11-14",km:229000,s:"Название сервиса",c:45000,cat:["ТО","Тормоза"],
 w:["Что делали","И ещё что делали"],
 p:["Запчасть с артикулом — 12 000 ₽"],
 n:"Заметка: что сказал мастер, что рекомендовал.",
 f:["IMG_0800"]},
```

- `d` — дата документа (не дата съёмки фото), `km` — пробег **с панели**, а не из карточки клиента.
  Если пробега в наряде нет, ставить `null`, а не выдумывать.
- `c` — сумма визита, `cat` — категории для поиска, `f` — номера фотографий.

Чтобы обновить статус узла, найти `const ITEMS` и поправить `ld` (дата) и `lk` (пробег)
у нужной строки. Даты «когда следующее» пересчитываются сами при каждом открытии страницы,
от сегодняшнего числа и расчётного пробега.

Точки для шкалы пробега вверху — отдельный массив `MILEAGE`. Туда добавлять только
достоверные значения: акты дилера, распечатки стендов развала, наряды крупных сервисов.

## Что где

| Раздел | Отвечает на вопрос |
|---|---|
| Шкала вверху | Где машина сейчас и где в истории дыры |
| План по этапам | Что делать первым при ограниченном бюджете и сколько это стоит |
| Статус по системам | Что просрочено, что скоро, что в норме — с поиском по слову |
| История | Что и когда делалось, из каких фото собрано |
| Слабые места | Что у OM642 и X166 ломается закономерно |
| Пробелы | Чего в архиве нет и что уточнить |

## Оговорки

- Пять точек пробега отбракованы: мелкие СТО переписывают значение из карточки клиента.
  Достоверны акты дилера, стенды развала и наряд mb-west от 25.08.2026.
- Строки с пометкой «не подтверждено» опираются на документы машины и практику форумов,
  а не на официальный источник MB. Перед дорогими работами уточнять у сервиса.
- Прогноз считается от 21 000 км/год. Если режим езды поменяется, поправить `kmPerYear`
  в блоке `const CAR`.
